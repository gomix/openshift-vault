# OpenShift Image Mode

## What is it?

In OpenShift, Image Mode is a newer operating model where the node's operating system and configuration are delivered as a bootable container image rather than being assembled on the node through traditional MachineConfig layering.

It is closely associated with:

- OpenShift 4.18+
- Hosted Control Planes (HCP)
- Edge deployments
- Image-Based Install (IBI)
- Future evolution of RHCOS management
